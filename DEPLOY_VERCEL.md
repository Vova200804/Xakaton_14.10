# Развёртывание демо на Vercel

1. На Vercel нажмите **Add New → Project** и импортируйте **Vova200804/Xakaton_14.10**.
2. **Root Directory:** корень репозитория (`./`). **Framework Preset:** Other.
3. **Node.js Version:** 24.x. Команда сборки `pnpm run build`, каталог результата `dist` уже заданы в `vercel.json`.
4. Нажмите **Deploy**. Переменные окружения и внешняя база для демо не нужны.
5. Откройте выданный адрес. На странице входа есть кнопка «Демонстрационные аккаунты».

## Поведение демо

Интерфейс, вход, тест, проекты, CMS, PDF и отчёты используют серверное API. Vercel запускает API как одну функцию; её временная SQLite-база и файлы находятся в `/tmp`. Изменения доступны в пределах одного работающего экземпляра. При новом экземпляре, перезапуске или новом деплое восстанавливаются исходные демонстрационные данные; может потребоваться повторный вход. При масштабировании разные экземпляры имеют независимые данные. Для показа используйте готовые демо-аккаунты.

Максимальный размер загружаемого файла на Vercel — **3 МБ**: JSON передаёт его в Base64, а [лимит запроса Vercel Functions](https://vercel.com/docs/functions/limitations) составляет 4,5 МБ. Большое видео можно указать HTTPS-ссылкой. Это демонстрация для хакатона; используйте вымышленные данные.

Локально `pnpm dev` сохраняет данные в `var/`, поддерживает файлы до 20/50 МБ и открывает http://127.0.0.1:4173.

## Проверка перед публикацией

```bash
pnpm install --frozen-lockfile
pnpm run build
pnpm test
node tests/vercel.mjs
```

`tests/vercel.mjs` проверяет обработчик функции с разобранным JSON, маршрутизацию, вход с HTTPS Origin, cookie Secure, приватные файлы, PDF, ограничения загрузки и сброс данных при новом экземпляре. Проверка выполняется локально; фактический деплой запускается в вашем аккаунте Vercel.
