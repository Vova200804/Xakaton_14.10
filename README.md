# Арктика — удивительная и неизведанная

**Демо на Vercel:** импортируйте этот репозиторий, выберите **Other**, корень `./`, Node.js **24.x** и нажмите Deploy. Конфигурация уже включена. [Подробная инструкция и ограничения демо](DEPLOY_VERCEL.md).

Локальный проект конкурса, собранный по 40 предоставленным экранам. Интерфейс на HTML/CSS/JavaScript, сервер Node.js, база SQLite. Регистрация, роли, профиль, согласия, тест с серверным дедлайном, проекты и файлы, приглашения педагога, оценки, публикация результатов, CMS и выгрузки работают с сохраняемыми данными.

## Запуск

Требуется **Node.js 24 или новее** и npm либо pnpm.

```bash
npm install
npm run dev
```

При использовании pnpm: `pnpm install --frozen-lockfile`, затем `pnpm dev`.

Открыть **http://127.0.0.1:4173**. Сервер по умолчанию слушает только этот ПК.

На Windows можно запустить `START.cmd` двойным щелчком. Он использует установленный Node.js (или среду Codex на этом ПК), при необходимости устанавливает зависимости через npm и запускает сервер. Оставьте окно открытым, пока пользуетесь сайтом.

Главная: `/#/home`. В правом нижнем углу — навигация по всем 40 экранам. Закрытые экраны требуют входа соответствующей роли. На странице входа есть кнопка «Демонстрационные аккаунты».

Для регистрации нового пользователя получить код кнопкой в форме. Он появится в **локальном почтовом ящике** — реальные письма не отправляются. Восстановление пароля тоже использует этот режим. Отметки согласия обязательны; у педагога согласие родителя не запрашивается.

## Данные и файлы

- `var/arctic.sqlite` — постоянная SQLite-база, создаётся при первом запуске.
- `var/` — приватные загрузки под серверными именами.
- База не обнуляется при перезапуске.
- `ARCTIC_STORAGE` позволяет выбрать отдельный каталог базы и файлов.
- `PORT` меняет порт, по умолчанию 4173.
- Черновик проекта можно сохранить без файла; для отправки требуется исследование PDF/DOCX до 20 МБ.
- Презентация PDF/PPTX, видео MP4 и другие разрешённые загрузки — до 50 МБ в локальной версии.
- Формат и размер проверяются сервером; приватные загрузки доступны только владельцу и разрешённым ролям.
- PDF сертификата генерируется с кириллическим шрифтом и настоящим QR-кодом после успешно завершённого теста. QR открывает публичную проверку документа без контактов пользователя. Отчёт скачивается в настоящем CSV или XLSX.

## Проверки

```bash
npm run build
npm test
```

`build` проверяет синтаксис модулей, 40 уникальных экранов и обязательные ресурсы. Внешняя сборка интерфейса не нужна: браузер получает готовые ES-модули из `dist/`.

Тесты самостоятельно запускают отдельные серверы на 4186, 4187 и 4188 с временными базами. На Windows браузерные тесты используют установленный Microsoft Edge в headless-режиме. Скриншоты и результаты сохраняются в `artifacts/`. API-тесты дополнительно проверяют сохранение после перезапуска.

- `tests/api.mjs`: серверные сценарии, роли, файлы, оценки, PDF, отчёты и отрицательные проверки.
- `tests/browser.mjs`: все 40 страниц, размеры 1536/768/390 px, изображения, ошибки консоли, поиск, контакты и диалог.
- `tests/flows.mjs`: сквозной сценарий через настоящие формы от регистрации до публикации оценки и новости.

По умолчанию тестовые пользователи, проекты и новости создаются только во временных базах. Если задать `TEST_URL`, браузерные тесты используют указанный сервер и изменяют его демонстрационные данные.

## Границы локальной версии

Это локальная демонстрационная реализация. Макеты содержат иллюстративные данные; официальные контакты, положение и научно проверенный банк вопросов не предоставлены.

Вход VK ID, SMTP, push/VK-рассылки и Zoom/Webinar не подключены. Форма контактов, сообщения и рассылки сохраняют записи локально. Дата защиты демонстрационная, действительной видеоссылки нет. В исходниках отсутствовало видео: вместо него показывается анимированная обложка с явной подписью.

Предпросмотр оценки содержит демонстрационные слайды и ссылки на реальные загруженные файлы. Автоматическая конвертация DOCX/PPTX в изображения не подключена. Карта регионов и историческая кривая регистрации — иллюстрации из макетов с подписью; живые списки и отчёты работают по базе.

Фотографии извлечены из растровых листов, поэтому часть небольших картинок имеет ограниченное разрешение. Чистый фон главной восстановлен ImageGen; фотографическая сцена и шрифты немного отличаются от оригинала. Полное совпадение пиксель в пиксель не заявляется.

Для размещения в интернете потребуется отдельная подготовка: заменить демонстрационные учётные записи и режим выдачи кодов, настроить почту/идентификацию/видеосервис, утвердить контент и конфигурацию сервера. Этот проект автоматически не публиковался.
