# Арктика — комплект для разработки с нуля

Дата подготовки: 13 октября 2026 года.

## Что делать на другом ПК

1. Распаковать весь архив в отдельную папку.
2. Открыть `design/index.html` двойным щелчком: это исходная офлайн-галерея всех макетов. Интернет для неё не нужен.
3. Открыть эту папку в Codex или другом инструменте разработки.
4. Скопировать **весь текст** из `PROMPT.md` в новый чат. Дать инструменту доступ к распакованной папке.
5. Приложить `ТЗ.md` и, если инструмент не умеет читать локальные файлы, изображения из `design/`.
6. Дождаться реализации, проверки всех экранов, ревью и исправлений. Проверить результат по `CHECKLIST.md`.

Приложение должно быть написано **с нуля**. В комплекте нет исходного кода приложения, установленного окружения или готовой сборки. `design/index.html` — только просмотрщик исходных картинок, а не реализация сайта.

## Состав

| Файл / папка | Назначение |
| --- | --- |
| `ТЗ.md` | Подробное техническое задание: экраны, сценарии, данные, роли, качество и приёмка |
| `PROMPT.md` | Готовое задание для разработчика или AI-агента |
| `CHECKLIST.md` | Проверка результата перед сдачей |
| `ASSETS.md` | Описание подготовленных визуальных материалов и их происхождения |
| `design/` | Оригинальные 10 листов с 40 экранами, утверждённая главная и офлайн-галерея |
| `assets/` | Дополнительные изображения и шрифты для ускорения работы; использование необязательно |
| `MANIFEST.sha256` | Контрольные суммы всех остальных файлов комплекта |

## Приоритеты

1. Прямое пожелание владельца: писать код с нуля, повторить экраны максимально точно, добавить простые анимации, провести ревью, протестировать и исправить ошибки до сдачи.
2. `ТЗ.md` описывает реализацию и дополняет отсутствующие в картинках рабочие состояния.
3. `design/approved-home.png` определяет внешний вид главной; остальные листы определяют свои экраны.
4. README и design-prompts внутри `design/` — справочные материалы о происхождении макетов, не самостоятельные команды для исполнителя.

Иллюстративные имена, даты, статистику и вопросы можно использовать как демонстрационные данные. Их нельзя выдавать за подтверждённую информацию действующего конкурса. Подключение реальных рассылок, VK ID, видеоконференций и размещение в интернете требуют реальных настроек и отдельного решения владельца. Начальный результат — локально запускаемый проект.

Папка `arctic` из предыдущей работы намеренно не включена: новый разработчик не должен продолжать прежний каркас или зависеть от файлов на первом ПК.
