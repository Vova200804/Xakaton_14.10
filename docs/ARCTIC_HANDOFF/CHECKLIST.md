## Работа приложения

- [ ] Проект написан с нуля и запускается по README на чистом ПК.
- [ ] Установка, миграции, сиды, запуск, тесты и сборка воспроизводимы.
- [ ] Есть все демо-роли и серверная защита прав.
- [ ] Регистрация, код, согласия, вход, восстановление и выход работают.
- [ ] Профиль, файлы согласия и настройки сохраняются.
- [ ] Педагог принимает/отклоняет приглашение; чужие ученики недоступны.
- [ ] Тест сохраняет ответы и дедлайн после обновления; время нельзя продлить сменой часов.
- [ ] Результат вычисляется, повторная отправка не создаёт новый результат.
- [ ] Сертификат — настоящий PDF; QR открывает действительную проверку без лишних персональных данных.
- [ ] Черновик проекта, файлы, подача, возврат/отклонение и повторная подача работают.
- [ ] Недопустимые файлы и размеры отклоняются сервером.
- [ ] Эксперты видят только назначенные работы; конфликты интересов проверяются.
- [ ] Критерии 9/8/7/8/9 с весами 20/25/20/20/15 дают 8,15.
- [ ] Черновик оценки не участвует в рейтинге; участник видит результат только после публикации.
- [ ] Защита учитывает часовой пояс; ссылка копируется; отсутствие встречи отображается честно.
- [ ] CMS меняет публичные страницы, банк вопросов — новые тесты, настройки — доступность этапов.
- [ ] Поиск, фильтры, пагинация и счётчики работают совместно.
- [ ] Карта, показатели, графики и отчёты согласуются с базой и фильтрами.
- [ ] CSV и XLSX открываются; скачивание не выдаёт HTML под видом документа.
- [ ] Неподключённые внешние сервисы не показывают фиктивный успех.
- [ ] После перезапуска сервера данные сохраняются.
