# Визуальные материалы

## Основные ориентиры

- `design/approved-home.png` — утверждённый вид главной: 1536 × 1024.
- `design/01-public.png` … `design/10-admin-ops-final.png` — исходные листы, каждый 1536 × 1024, по четыре экрана.
- Порядок четвертей: верхняя левая, верхняя правая, нижняя левая, нижняя правая.
- Точные границы страниц немного отличаются между листами. Не включать в интерфейс внешнюю рамку, номера экранов, подписи и промежутки между четвертями.
- Исходные PNG неизменны. Проверять дизайн по ним, а не по повторно сжатым материалам.

## Фон главной

`hero.webp` — **новое вспомогательное изображение**, исходные макеты не менялись. Генерация удалила текст и элементы интерфейса, но немного изменила фотографическую сцену. Это не точная копия исходной фотографии. Для строгого совпадения улучшить извлечение/восстановление фона и сверить с approved-home.png.

Использован встроенный ImageGen. Задание: убрать все надписи, логотипы, линии, кнопки, координаты и нижний белый блок; сохранить медведя справа, горы в центре, лёд, тёмную левую часть, закат справа, северное сияние и композицию обложки. Ожидаемый результат — только чистая широкая фоновая сцена без текста.

## Шрифты

- `manrope-0.ttf` … `manrope-4.ttf`: веса 400, 500, 600, 700, 800.
- `anton-0.ttf`: вес 400, вспомогательный латинский акцентный шрифт. Для слова «АРКТИКА» не подходит.
- Источник: Google Fonts, семьи Manrope и Anton. Подобраны как приближение к растровому макету; исходный шрифт в комплекте дизайна не указан.
- Проверена сигнатура файлов; это **TrueType**, расширение исправлено на `.ttf`. При подключении использовать `format('truetype')`; для веб-оптимизации можно отдельно конвертировать в WOFF2.
- Проверка таблицы символов: Manrope поддерживает «АРКТИКА», Anton **не содержит кириллицы**. Для крупной надписи выбрать узкий жирный кириллический шрифт, приложить лицензию и сверить форму слова с макетом. Не допускать незаметной замены Anton системным шрифтом.
- Лицензии приложены: `manrope-OFL.txt` и `anton-OFL.txt`. Сохранять их при распространении. Интернет не нужен для использования уже приложенных локальных файлов.
